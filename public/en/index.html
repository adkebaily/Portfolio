From idea to AI agent

The six steps I follow to design a generative AI solution. CK-AI, this site's agent, was built this way.

  1. 1

    Understand the need

    Define the use case, the users and what a good answer must contain.

  2. 2

    Write the prompts

    Clear instructions, examples and rules to guide the model.

  3. 3

    Provide context

    Give the model the right information: documents, profile, knowledge base.

  4. 4

    Connect tools

    Connect the model to tools so it can act, not just answer.

  5. 5

    Evaluate and protect

    Measure answers on labelled data, reduce errors and misuse.

  6. 6

    Integrate

    Deploy in a web or mobile app through a secure API.

AI agent for administrative document processing

Personal project, 2026

A citizen uploads their documents (tax notice, proof of address, bank details…). The agent cleans the image (denoising, Sauvola binarisation, deskewing), reads it with OCR, identifies the document, extracts the fields with an LLM and checks whether the file is complete. Uncertain cases go to human validation.

Python, OpenCV, Tesseract, LLM (Claude), FastAPI, PostgreSQL, n8n, Docker
