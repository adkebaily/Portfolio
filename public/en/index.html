From idea to AI agent

How I design a generative AI solution.

A useful AI agent is more than a good model: it needs a clear goal, precise prompts, the right context, well-chosen tools and honest evaluation. A real example: CK-AI, this site's assistant.

  1. 01

    Understand the need

    Define the use case, the users and what a good answer must contain.

  2. 02

    Prompt engineering

    Write clear instructions, examples and rules to guide the model.

  3. 03

    Data & context

    Give the model the right information: documents, profile, knowledge base.

  4. 04

    Agents & tools

    Connect the model to tools and steps so it can act, not just answer.

  5. 05

    Evaluation & guardrails

    Test the answers, reduce errors and protect against misuse.

  6. 06

    Integration

    Deploy the solution in a web or mobile app through a secure API.

AI agent for administrative document processing

Personal project · AI in public services · 2026

A citizen uploads their documents (tax notice, proof of address, bank details…). The agent cleans the image (denoising, Sauvola binarisation, deskewing), reads it with OCR, identifies the document, extracts the fields with an LLM and checks whether the file is complete; uncertain cases go to human validation. Results on 40 labelled documents: 100% classification accuracy, 97.6% field accuracy, OCR error divided by 90 thanks to preprocessing.
