AI agent for administrative document processing

Personal project · AI in public services · 2026

A citizen uploads their documents (tax notice, proof of address, bank details…). The agent cleans the image (denoising, Sauvola binarisation, deskewing), reads it with OCR, identifies the document, extracts the fields with an LLM and checks whether the file is complete; uncertain cases go to human validation. Results on 40 labelled documents: 100% classification accuracy, 97.6% field accuracy, OCR error divided by 90 thanks to preprocessing.
