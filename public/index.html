De l'idée à l'agent IA

Les six étapes que je suis pour concevoir une solution d'IA générative. CK-AI, l'agent de ce site, a été construit ainsi.

  1. 1

    Comprendre le besoin

    Définir le cas d'usage, les utilisateurs et ce qu'une bonne réponse doit contenir.

  2. 2

    Écrire les prompts

    Des instructions claires, des exemples et des règles pour guider le modèle.

  3. 3

    Donner le contexte

    Fournir au modèle les bonnes informations : documents, profil, base de connaissances.

  4. 4

    Brancher les outils

    Connecter le modèle à des outils pour qu'il agisse, pas seulement qu'il réponde.

  5. 5

    Évaluer et protéger

    Mesurer les réponses sur des données annotées, limiter les erreurs et les abus.

  6. 6

    Intégrer

    Déployer dans une application web ou mobile, via une API sécurisée.

Agent IA de traitement de dossiers administratifs

Projet personnel, 2026

Un usager dépose ses pièces (avis d'imposition, justificatif de domicile, RIB…). L'agent nettoie l'image (débruitage, binarisation de Sauvola, redressement), la lit par OCR, identifie le document, extrait les champs avec un LLM et vérifie si le dossier est complet. Les cas incertains partent en validation humaine.

Python, OpenCV, Tesseract, LLM (Claude), FastAPI, PostgreSQL, n8n, Docker
